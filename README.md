# Chengyu Hu — Portfolio

A buildless personal portfolio. Open `dist/index.html` through a web server.

The site follows the reference's presentation model: a full-screen cover, selected project banners, full-screen galleries of original portfolio boards, an archive, profile and contact information. All imagery and personal content come from Chengyu Hu's supplied Figma portfolio. No reference designer imagery or personal information is included.

## Update

- Project definitions and page labels: `dist/app.js`.
- Visual styles and responsive rules: `dist/styles.css`.
- Profile and contact content: `dist/index.html`.
- Image files: `dist/assets/`.

Gallery boards are optimized WebP exports, normally 2953 × 1316. `leafwell-08.webp` is 2400 × 1070. Text remains embedded in the original boards; the surrounding navigation and project summaries are semantic HTML. Click any board to enlarge; the enlarged view supports scrolling, zoom controls, keyboard +/−/0, and Escape. Each project supports a `#project-<id>` link.
